# Claude 상담 매니저 통합

## 기준 시나리오

- 기준: itproanalysis/donghaeng_finance_ai, feature/demo-scenario, aee1dda6df7b65fc69f0b70fd6b58a6564ca9788.
- 현재 앱은 느티나무감자탕 시나리오의 12개 정보 코드, 질문, 검증용 답변을 모두 사용한다.
- 각 질문에는 수집 목적과 반드시 확인할 항목을 함께 정의한다. 화면, Claude 요청, 검증이 같은 `app/demo/scenario.ts`를 읽는다.

## 권한 경계

- 서버가 다음 질문 ID와 순서를 결정한다.
- Claude는 마지막 답변을 짧게 확인하고, 서버가 정한 다음 질문의 표현만 자연스럽게 바꾼다.
- Claude가 다른 질문 ID를 반환하거나 응답 형식이 맞지 않으면 결과를 적용하지 않는다.
- Claude는 답변 저장, 완료 상태, 관리자 검토, 금융 판단을 변경할 수 없다.
- API 키가 없거나 요청이 실패해도 고정 질문 기준선으로 인터뷰를 계속한다.

## 개인정보와 운영

- 인터뷰에서 답변을 보내면 다음 질문을 준비하기 위해 Anthropic Messages API를 호출한다.
- `ANTHROPIC_API_KEY`는 서버 환경 변수로만 읽고 브라우저 코드나 저장소에 포함하지 않는다.
- 요청에는 현재 질문 프레임워크와 최근 답변 다섯 개만 포함한다.
- 기본 모델은 `claude-sonnet-5`, 제한 시간은 8초, 최대 출력은 450토큰이다.
- 대출 승인, 거절, 신용등급, 점수, 자격 판단을 프롬프트에서 금지한다.
